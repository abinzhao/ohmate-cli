# 0001：同源 Runtime 与渐进底座迁移

状态：采用。依据：OHMate 9.0 主合同。维护责任：项目开发者，通过本地测试、构建和入口验收维护本决定。

目标是在指定 DevEco 源码上建立可运行的 OHMate 工程，保留原命令，终端与 Web 共用执行与事实模型。约束为单人维护、Node ≥22、五 workspace、ESM、MIT 来源及默认本地隐私。编译器、HDC、SDK、Profiler 仍由官方工具负责。

| 驱动力 | 方案响应 |
| --- | --- |
| 终端功能完整 | 原命令逐叶登记；新服务同时暴露 CLI 与 Web |
| 长驻进程安全 | 领域返回结果，入口处理 stdout/退出；旧命令子进程隔离 |
| 可恢复且可审查 | TaskStore 保存计划、批准范围、事件、结果和 receipt |
| 避免双维护 | 复用源码领域；AgentAdapter 可替换，不维护独立完整 pi fork |

| 备选 | 处置 |
| --- | --- |
| 保持快照不改 | 无 OHMate 入口，无法满足产品合同 |
| 包装外部 devecocli | 安装和版本漂移，违反指定源码底座路线 |
| Web 直接调用 Commander action | 全局 cwd、exit、日志、钩子会污染服务 |
| 一次重写所有原领域 | 回归范围过大；采用逐项隔离与迁移 |

正向结果：同一注册和策略、可重用领域、终端独立、无模型确定性流程。
成本：旧命令隔离增加启动成本，旧 JSON/错误需归一；需防止协议流被包装。

数据方向：CLI/Web/Agent → Registry → Domain/LegacyAdapter → 官方工具；
事件、产物和证据 → TaskStore/Report。Registry 不依赖 Commander；命令目录是
对原注册的翻译，不能拿未实现的工具描述代替执行证据。

任务存储采用本机目录、原子文件和追加事件，避免新增数据库服务。损坏或不兼容
记录明确报错；重启先核对执行和批准状态，不重发副作用。并发控制在项目写入、
设备目标和任务持久化边界完成。交互使用请求/响应与有序事件读取，避免浏览器
和终端各自保存运行状态。

| 边界 | 事实模型 | 上游 / 下游与关系 | 检查责任 |
| --- | --- | --- | --- |
| Registry | ToolSpec、输入输出 Schema | CLI/Web/Agent 共享内核；领域为下游 | Runtime 契约测试 |
| LegacyAdapter | argv、进程、真实退出与原始输出 | 翻译底座输出，隔离全局副作用 | 子进程/协议测试 |
| TaskStore | Task、计划、批准、事件、receipt | Runtime 生产，CLI/Web 消费 | 状态/重启/并发测试 |
| Toolchain | 路径、版本、可用性 | 遵循原 ToolProvider 模型 | 环境与 fake 工具测试 |
| AgentAdapter | 上下文、工具事件、预算 | 受 Registry 策略约束 | provider POC 与故障测试 |

| 不变量 | 门槛 / 来源 | 检查与失败响应 |
| --- | --- | --- |
| 导入无副作用 | 无写入/调度/退出，子进程观察 | 每次改入口运行；失败阻止完成 |
| Web/CLI 同源 | ToolSpec 差集为零 | 每次改注册运行映射测试 |
| 机器输出保真 | JSON 单信封；MCP/LSP 原协议 | built 入口测试；混杂输出即失败 |
| 默认隐私 | 无遥测/自动更新/Skill 迁移 | 无凭据临时目录测试 |
| 取消收尾 | 子进程结束、receipt 记录取消 | 观察实际就绪与结束，不靠固定睡眠 |
| 可用性真实 | unknown/degraded 不标 passed | 缺工具/缺设备/缺 Producer 负例 |

外部运行依赖采用原适配，可从路径/版本和原诊断定位。缺少官方工具时保留
工程分析和离线能力，设备或 Producer 缺失只禁用对应请求。Agent provider
失败不切换付费服务；移除 adapter 不应影响确定性能力。

风险：命令漂移（中/高，目录对账）、旧副作用（中/高，隔离与导入测试）、
任务恢复重复写（中/高，批准哈希与真实状态核验）、证据误标（中/高，来源与
状态测试）、包资源缺失（中/高，打包后独立安装验收）。

可逆性：两向门。可按模块替换 LegacyAdapter 或存储实现；公共 ToolSpec、
退出码和事件须保持兼容。若启动成本或恢复可靠性无法满足实测要求，则优先
迁移高频领域或调整存储，不能退回 Web 专用业务实现。
